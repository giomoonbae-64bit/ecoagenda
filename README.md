# 🌿 EcoAgenda

O **EcoAgenda** é um sistema de agendamento online sustentável projetado para substituir agendas físicas de papel por uma solução digital elegante, rápida e ecológica. 

A aplicação calcula automaticamente a pegada ecológica positiva poupada pelo usuário através do volume de agendamentos digitais criados, incentivando práticas de sustentabilidade corporativa e pessoal.

---

## 🚀 Funcionalidades Principais

*   **Página Inicial Interativa**: Painel intuitivo com apresentação conceitual e **contador em tempo real de impacto ecológico** (folhas de papel economizadas, água preservada e agendamentos realizados).
*   **Agendamento Inteligente**:
    *   Formulário intuitivo com validação integrada e máscara para telefone.
    *   **Prevenção de Conflitos**: O sistema analisa as marcações existentes e exibe unicamente horários disponíveis para a data selecionada.
    *   Fuso horário local integrado para evitar divergências.
*   **Painel Administrativo Completo**:
    *   Listagem organizada com controle visual de status (Pendente / Confirmado).
    *   Filtros inteligentes por data, status e campo de busca textual (nome, telefone ou serviço).
    *   Ferramentas integradas para **Confirmar**, **Editar** (via modal interativa) ou **Excluir** agendamentos.
*   **Bloqueio de Datas**:
    *   Módulo para administradores bloquearem datas específicas (feriados, recessos, etc.).
    *   Tratamento instantâneo no formulário de agendamento, desabilitando as datas bloqueadas e exibindo o motivo definido.

## 🎨 Design & Visual

*   **Tema Sustentável**: Paleta de cores selecionada focando em tons de verde, branco e cinzas suaves.
*   **Interface Premium**: Cards com efeito glassmorphism, sombras suaves, botões responsivos e micro-animações nas trocas de telas.
*   **Responsividade**: Totalmente otimizado para celulares, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias nativas do desenvolvimento web (*Vanilla Web Stack*), sem dependências ou frameworks complexos:

*   **HTML5** para marcação semântica.
*   **CSS3** com variáveis CSS, layouts flexbox/grid e animações nativas.
*   **JavaScript (ES6+)** para manipulação da DOM e lógica de regras de negócio.
*   **Web Storage API (localStorage)** para persistência local dos dados, sem necessidade de banco de dados externo ou servidor.
